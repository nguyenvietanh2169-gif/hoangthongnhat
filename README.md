# Viettel Tammii - Website Hệ Sinh Thái Giải Pháp Doanh Nghiệp & Hộ Kinh Doanh

Dự án website chuyên nghiệp được phát triển dựa trên poster dịch vụ của **Trương Phước Hoàng - Viettel Tammii**, tham khảo phong cách thiết kế hiện đại của [Viettel Telecom (vietteltelecom.vn)](https://vietteltelecom.vn/vx/).

---

## 🌟 Điểm nổi bật của Website

1. **Chuẩn nhận diện thương hiệu Viettel Telecom:**
   - Gam màu đỏ Viettel đặc trưng (`#EE0033`), tông trắng, xám bạc và hiệu ứng ánh sáng công nghệ (Cyber Blue & Cloud Grid).
   - Phông chữ chuẩn tiếng Việt `Be Vietnam Pro` sang trọng, hiện đại.
   - Bố cục thẻ bo góc, đổ bóng tinh tế, hiệu ứng micro-interaction mượt mà.

2. **Đầy đủ 10 dịch vụ cốt lõi từ Poster:**
   - **Chữ ký số Viettel-CA** (USB Token, Cloud-CA, HSM)
   - **Hóa đơn điện tử S-Invoice** (Tích hợp máy tính tiền, chuẩn Thông tư 78)
   - **Phần mềm bán hàng Tendoo (FOS)** (Quản lý kho, POS, in hóa đơn tức thì)
   - **Hợp đồng điện tử vContract** (Ký kết từ xa mọi lúc mọi nơi chuẩn Bộ Công Thương)
   - **Phần mềm BHXH Viettel (vBHXH)** (Kê khai bảo hiểm xã hội điện tử 1-click)
   - **Phần mềm Y tế & Giáo dục** (HIS/LIS phòng khám, SMAS trường học)
   - **Kế toán dịch vụ & Kê khai thuế HKD** (Báo cáo thuế trọn gói, giải trình thuế)
   - **Hỗ trợ Đăng ký Giấy phép kinh doanh** (Thành lập công ty, mở hộ cá thể cấp tốc 3 ngày)
   - **Sim Viettel số đẹp** (Hotline doanh nghiệp, số phong thủy, tứ quý, tam hoa)
   - **WIFI & Thiết bị phát 4G-5G** (Cáp quang IP tĩnh doanh nghiệp, WiFi Mesh)

3. **Tính năng tương tác chuyển đổi cao (High Conversion):**
   - **Bảng tính chi phí Combo tự động:** Khách hàng tích chọn các dịch vụ mong muốn, hệ thống tự động tính thành tiền, áp dụng chiết khấu combo (10% - 20%) và chuyển sang form đăng ký.
   - **Bộ lọc dịch vụ (Filter Tabs):** Lọc theo nhu cầu: Tất cả, Doanh nghiệp SME, Hộ kinh doanh cá thể, Hạ tầng Viễn thông.
   - **Bộ 3 gói Combo khuyến mãi:** Combo Khởi sự HKD, Combo Doanh nghiệp mới, Combo Bán lẻ F&B.
   - **Nút liên hệ nổi (Floating Actions):** Gọi hotline `08 1789 1789` (hiệu ứng nhịp tim), Chat Zalo, Lên đầu trang.
   - **Modal tư vấn nhanh & Toast thông báo thành công:** Trải nghiệm tức thì cho khách hàng.

## 🚀 Cách mở và chạy thử Website

### Cách 1: Mở trực tiếp (Không cần cài đặt)
Chỉ cần nhấp đúp vào file `index.html` trong thư mục:
`/Users/nguyenvietanh/.gemini/antigravity/scratch/viettel-tammii-web/index.html` để mở ngay trên trình duyệt (Chrome, Safari, Edge,...).

### Cách 2: Chạy qua Python Web Server
Mở terminal và gõ:
```bash
cd /Users/nguyenvietanh/.gemini/antigravity/scratch/viettel-tammii-web
python3 -m http.server 3000
```
Sau đó truy cập [http://localhost:3000](http://localhost:3000).

### Cách 3: Chạy qua Node.js (npx serve)
```bash
cd /Users/nguyenvietanh/.gemini/antigravity/scratch/viettel-tammii-web
npx serve .
```
